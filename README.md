# Persboy (fruitland)

فروشگاه آنلاین میوه و سبزیجات — پیاده‌سازی جدید.

وضعیت فعلی پروژه، معماری، و آنچه واقعاً پیاده و تست شده در [`CLAUDE.md`](./CLAUDE.md) مستند است.

## دستورها

```bash
npm install
npm run dev        # اجرای اپ روی http://localhost:3000
npm run verify      # lint + typecheck + test + build
npm run test:e2e    # Playwright (نیاز به build و اجرای سرور)
```
